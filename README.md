# ПРОФ ЕКБ — лендинг

Одностраничный сайт бухгалтерской и юридической компании «ПРОФ ЕКБ» (Екатеринбург).

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # статическая сборка в ./out
```

Сборка статическая (`output: "export"`), поэтому папку `out/` можно положить
на любой хостинг: nginx, Vercel, Netlify, обычный shared-хостинг по FTP.
Сервер Node.js не нужен.

## Стек

- **Next.js 16** — App Router, статический экспорт
- **Motion** — анимации: закреплённая сцена в первом экране, появление секций, счётчик в калькуляторе
- **Tailwind CSS 4** — токены дизайн-системы объявлены в `app/globals.css`

## Как устроено

| Файл | Что внутри |
|---|---|
| `lib/content.ts` | Все тексты, цены и факты. Правки контента — только здесь. |
| `components/Stage.tsx` | Первый экран: ноутбук закрепляется, экран пересобирается на каждом шаге прокрутки, подписи меняются. |
| `components/Screen.tsx` | Интерфейс учётной системы — пять состояний плюс компактный вариант для телефонов. |
| `components/Calculator.tsx` | Калькулятор стоимости на реальной матрице цен из прайса. |

Прокруткой управляет `Stage.tsx`: раскадровка задана константами `HERO_VH` и
`STEP_VH` — из них считается высота секции и границы шагов. Хотите держать шаг
дольше — увеличьте `STEP_VH`.

## Дизайн-решения

- **Шрифты:** Unbounded (заголовки), Golos Text (текст), JetBrains Mono (цифры и таблицы) — все с кириллицей.
- **Цвет:** страница светлеет по мере прокрутки, от чернильного первого экрана к бумажному листу. Акцент — фуксия, цвет пиджака Марии с пресс-волла налоговой конференции.
- **Контраст:** приглушённый текст задан отдельными цветами (`--color-ink-muted`, `--color-paper-muted`), а не прозрачностью, чтобы держать 4.5:1 на обеих подложках. На тёмном фоне фуксия заменяется осветлённой: исходная даёт 3.7:1.
- **Движение:** `MotionConfig reducedMotion="user"` — при системной настройке «уменьшить движение» смещения отключаются, остаются только затухания.

## Что нужно доделать перед публикацией

1. **Приём заявок.** Формы пока открывают почтовую программу через `mailto:`
   (`components/Contact.tsx`, функция `submit`) — так она работает на статике
   без бэкенда. Когда появится обработчик, замените тело `submit` на `fetch`
   к нему.
2. **Политика конфиденциальности.** Чекбокс согласия есть, отдельной страницы с
   политикой нет — для сбора персональных данных она нужна.
3. **Аналитика.** Яндекс.Метрика или другой счётчик не подключены.
4. **Фотографии.** Взяты из Telegram-канала владельца; для печати и ретины
   лучше исходники в большем разрешении.
