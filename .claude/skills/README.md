# Skills

Third-party skills installed for use while building this site. Each folder is a
self-contained Claude Code skill (`SKILL.md` + supporting files) invoked
automatically by Claude when relevant, or explicitly via `/skill-name`.

| Skill | Source | Purpose |
|---|---|---|
| `frontend-design` | [anthropics/claude-code](https://github.com/anthropics/claude-code/tree/main/plugins/frontend-design/skills/frontend-design) | Distinctive visual design direction (palette, type, layout, motion) instead of generic AI-template aesthetics. |
| `clone-website` | [JCodesMore/ai-website-cloner-template](https://github.com/JCodesMore/ai-website-cloner-template) | Reverse-engineer and rebuild a reference site section-by-section (assets, CSS, content) when cloning/replicating a design. |
| `ui-ux-pro-max` | [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill) | Searchable UI/UX design intelligence: styles, palettes, typography pairings, accessibility/UX guidelines, icons, charts, stack-specific implementation notes. |

Licenses are included in each skill's own folder.
